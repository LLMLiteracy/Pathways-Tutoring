# Pathways Tutoring

Website for Pathways Tutoring — certified 1-on-1 online tutoring for university students. Built with React, TypeScript, Vite, Tailwind CSS, React Router, and Supabase.

See [build-spec.md](./build-spec.md) for the full build specification.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
